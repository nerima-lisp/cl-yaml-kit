# cl-yaml-kit

`cl-yaml-kit` is a Common Lisp reader and writer for YAML 1.2.2. It exposes
value, representation-node, and event APIs, with Core, JSON, and Failsafe
schema selection.

Start with [Getting Started](getting-started.md), then use the
[API Reference](reference/api.md) for exported symbols. The [Data Model](guide/data-model.md)
and [Writing](guide/writing.md) pages describe the value and output contracts.
Conformance measurements and known gaps are recorded in
[Conformance](reference/conformance.md).
